# Kötészet

Könyvoldalak fotóiból kereshető (képes) PDF és EPUB, magyar szövegfelismeréssel, a telefonon.

- Telepíthető webapp (PWA): Chrome-ban megnyitva a menüből „Alkalmazás telepítése”.
- Minden adat a készüléken marad; a szövegfelismerés (Tesseract) helyben fut, a képek sehová nem kerülnek fel.
- Kimenet: képes PDF láthatatlan szövegréteggel, EPUB fejezetekkel és borítóval, szöveges PDF, TXT.

Felhasznált nyílt forrású elemek: tesseract.js (Apache-2.0), magyar nyelvi adat (tessdata, Apache-2.0), jsPDF (MIT), JSZip (MIT), DejaVu Serif, Literata (OFL).
